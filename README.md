# BasicChatbot
A rule-based chatbot built with Python using functions and logic to simulate human-like conversations.

 # Overview 
This is a basic Python chatbot that replies to simple user inputs like "hello", "how are you", and "bye".

It uses functions, if-elif-else logic, loops, and input/output to keep the conversation running until the user says "bye".

 # How It Works
Function → get_bot_response() checks the user’s message and returns a reply.

if-elif-else → Decides which reply to give based on input.

Random choice → Replies are chosen randomly from a list, so they feel more natural.

Loop → Keeps the chatbot running until "bye" is typed.

Input/Output → input() takes user text, print() shows bot reply.
